# Rust Investment Wallet

Projeto desenvolvido durante o **Santander Bootcamp Rust AI Developer**, oferecido pela [DIO](https://www.dio.me/).

A proposta do projeto é desenvolver, ao longo do bootcamp, uma **API para gerenciamento de uma carteira de investimentos**, utilizando Rust e tecnologias do ecossistema.

## 🚧 Status

Em desenvolvimento.

Este projeto está sendo construído progressivamente durante o bootcamp, portanto novas funcionalidades serão adicionadas conforme o desenvolvimento avançar.

## 🛠️ Tecnologias

* Rust
* Axum
* Tokio
* Serde
* Tracing
* Color-eyre

## 🎯 Objetivo

Praticar o desenvolvimento de uma aplicação backend em Rust, explorando conceitos como:

* APIs REST
* Roteamento
* Estado compartilhado
* Concorrência assíncrona
* Serialização e desserialização
* Logging e instrumentação
* Gerenciamento de dependências com Cargo

## ▶️ Executando o projeto

Clone o repositório e entre na pasta:

```bash
git clone https://github.com/Pancosta/rust-investment-wallet.git
cd rust-investment-wallet
```

Execute:

```bash
cargo run
```

A aplicação será iniciada na porta `3000`.
